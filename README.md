# طريقة الحصول على ملف APK (بدون تثبيت أي برنامج)

1. أنشئ حساباً مجانياً على github.com
2. أنشئ مستودعاً جديداً (New repository) ثم ارفع كل محتويات هذا المجلد (تأكد من رفع مجلد .github أيضاً)
3. افتح تبويب Actions ثم Build APK ثم Run workflow
4. بعد 3-5 دقائق افتح العملية المكتملة ونزّل attendance-apk من قسم Artifacts
5. فك الضغط وانقل app-debug.apk إلى الهاتف وثبّته (فعّل "التثبيت من مصادر غير معروفة")
